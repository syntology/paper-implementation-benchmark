#            src/vendor/bedrock_client.py for its exception types, so it is
#            declared rather than assumed
#   requests the outbound HTTP gateway the `search` arm goes through. It is a
#            module-level import in src/vendor/api_gateway.py, which

#            imports unconditionally -- so WITHOUT IT NO ARM STARTS, not even

#            listed here.

#           outside Syntology) and `code_only`'s code_get
#   scipy   OPTIONAL -- sharpens one Wilcoxon p-value in
#           analyze_substitution.py, which falls back to a normal
#           approximation without it
#
# Versions are floors, not pins: the runs used Python 3.14 and the referee's
# property suites are ordinary numpy. If a suite stops passing on your version,
